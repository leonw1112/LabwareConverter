# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**, then **Report a vulnerability**.
3. Include affected files or workflows, reproduction steps, impact, and environment details.

If private vulnerability reporting is unavailable, open an issue marked with the
`security` label and state that it contains a security concern. Do not publish sensitive
details or exploit code in a public issue.

Please allow reasonable time for the maintainer to investigate and respond before
public disclosure. Reports affecting generated labware or VENUS installations should
describe the production impact without sharing confidential labware data.

## Supported versions

The repository's `main` branch is the supported version. Releases are not currently
published through a formal support or maintenance policy.
